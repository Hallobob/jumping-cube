# Jumping Cube Deluxe

A small, dependency-free browser game. Open `index.html` in a browser to play.

Press **Space** or click/tap to start and jump. Hold the control to steer in Wave
and Ship modes; in Gravity mode each press flips gravity. Clear Level One to
unlock Level Two, where jump pads launch the cube and a Tram mode joins the run.
Avoid obstacles, collect coins, and clear both levels. Your best distance is
saved locally when browser storage is available.
