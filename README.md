# Jumping Cube Deluxe

A small, dependency-free browser game. Open `index.html` in a browser to play.

Choose one of three levels and a game speed on the home screen before starting.
Use **← / →** to choose a level and **↑ / ↓** to choose Chill, Normal, or Turbo
speed, or click the options.
Press **Space** or click/tap to start and jump. Hold the control to steer in Wave
and Ship modes; in Gravity mode each press flips gravity. In Tram mode, press
**Space** or click to switch between the ceiling and floor tracks. Use the
in-game **Home** button (or **H** / **Escape**) to return to level selection.
Level Two features jump pads and Tram mode; Level Three combines all six game
modes. Avoid obstacles, collect coins, and clear the levels. Your best distance
is saved locally when browser storage is available.
