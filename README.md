# Jumping Cube Deluxe

A small, dependency-free browser game. Open `index.html` in a browser to play.

Choose one of four levels and a game speed on the home screen before starting.
Use **← / →** to choose a level and **↑ / ↓** to choose Chill, Normal, or Turbo
speed, or click the options.
Press **Space** or click/tap to start and jump. In Ball mode, hold the jump
control during ascent for a higher jump. Hold the control to steer in Wave and
Ship modes; in Gravity mode each press flips gravity. In Tram mode, press
**Space** or click to switch between the ceiling and floor tracks. Level Four
is a tougher challenge with a hidden mode. Use the in-game **Home** button (or
**H** / **Escape**) to return to level selection.
Level Two features jump pads and Tram mode; Level Three combines all six game
modes. Avoid obstacles, collect coins, and clear all four levels. Your best
distance is saved locally when browser storage is available.
